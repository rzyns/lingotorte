## 3. Task walkthroughs

**A. Load (ideal ≤ 4).** Fixture: Library (1) → *Load synthetic fixture* (2) → Player with video, PL+EN overlay and 2 clickable lines `[observed]`. **2.** Real files: Library (1) → *Choose subtitles* (2, picker: `dialogue.pl.srt` + `dialogue.en.srt` injected) → the app shows "Target: dialogue.pl.srt · Native: dialogue.en.srt · Swap" (auto-assigned by language tag) → session *Choose video* (3, picker: `synthetic-polish-dialogue.webm`) → *Import local media* (4) → Player, "Transcript ready", overlay "Cześć, to jest lokalny test. / Hello, this is a local test." `[observed]` **4 = ideal.** The persistent *Choose video (recommended)* path is counted only up to its native picker: Library (1) → Choose subtitles (2) → Choose video (3, picker) → ? `[inferred]` ≤ 4 if that picker imports directly. **Friction:** P4/P6. **Fix direction:** rename the session-only button to e.g. "Use a one-time copy" and visually demote it.

**B. **C. Review (ideal 0 setup; Space + 1–4).** Review nav: "Recognize: lokalny" was already due, with **0 setup clicks**. With focus on body, `Space` revealed the back: "Meaning: local", source line, native line, Again 1 / Hard 2 / Good 3 / Easy 4. `3` rated the card and the queue emptied ("No cards due right now") `[observed]`. **0 clicks; Space + 3 = ideal.** Front ≠ back. After the last rating, focus lands on `P.empty-state` (fine). **Friction:** none found.
