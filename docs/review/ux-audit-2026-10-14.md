## 0. Diagnosis

The app now looks finished. The grid bug, the unstyled views and the subtitle/control collision are gone, and saving a word or sentence with a meaning, with toast and Undo, and having it reach Review without any setup works end to end. **Ugliness:** what remains is Player clutter, not missing CSS. Between the controls and the capture form, the left column always shows a "Source range" slider panel and an "Owned local media path / Prepare source audio" panel. These panels are full of developer jargon, and they push the capture form about 1,000 px below the video. **Friction:** the biggest remaining cost is in Task B. Clicking a transcript word scrolls the page to that distant capture form (`scrollY` 0 → 1163 at 1280×800), so the video leaves the screen at the moment of capture. Task C still has no `Space` / `1–4` review shortcuts.

## 3. Task walkthroughs

**A. Load (ideal ≤ 4 incl. pickers).** Fixture path: Library (1) → *Load synthetic fixture* (2) → Player auto-opens with video, dual subtitles and clickable words `[observed]`. **2 clicks.** Real-file path, counted from the UI up to the pickers: Library (1) → *Import copy* file input (2, picker) → target .srt (3, picker) → native .srt (4, picker) → *Import local media* (5) = **5**, same as the previous audit. The persistent-handle path *Choose video (recommended)* (1 click to picker) could not be followed past the native picker, so its total is unverified. **Friction:** one step over the ideal, plus the open Transcript tools on first visit (N9). **Fix direction:** let *Choose video* also accept the subtitle files in the same picker and auto-assign target/native, which gives ≤ 3.

**B. Watch & collect (ideal 1 gesture + optional meaning).** Word: click word (1) → Meaning focused → type → Enter. Result: saved, toast "Saved “lokalny” · Undo", rail "1 saved / 1 due today" `[observed]`. **1 gesture + meaning + Enter.** Sentence: *Save sentence…* (1) → same form, Meaning focused → Enter. Undo restores the selection and meaning `[observed]`. Shift+click → phrase, drag → phrase, Tab to cue row → ArrowRight → Enter → word: all open the same form `[observed]`. Alt+click and double-click loop could not be exercised because the fixture has no word timings, so both are no-ops by design `[code]` `views/player/transcript.ts:307-319`. Typing in transcript search while playing kept the video playing (t 0.65→1.58 s) `[observed]`. **Friction:** N7, and Review never sees a card without meaning if the learner skips the field (OK, meaning is optional and the native line backs the card). **Fix direction:** dock the capture form next to the clicked line or in the sticky transcript aside instead of scrolling the page.

**C. Review (ideal 0 setup clicks; Space + 1–4).** Save → Review nav: the card "Recognize: lokalny" was already there, with no "Create review card" step `[observed]`. **0 setup clicks.** The back side differs from the front: "Meaning: local" plus the source line and the native line `[observed]`. Due shows as "1 card · next due now", and scheduling sits in `<details>`. The review itself took **2 clicks per card** (Show answer, Good). `Space`/`3` did nothing (N6). **Fix direction:** Review-scoped keydown, with Space = reveal and 1–4 = rate.
